HOW IT WORKS
================================================================================

USER VIEW:
1. Open customer profile
2. Scroll to Purchase History
3. See transactions with status badges
4. Click transaction to expand
5. See "Process Return" button (if eligible)
6. Click button → ReturnsModal opens pre-filled
7. Select items and refund method
8. Complete return
9. View refreshes with new RETURNED status

DEVELOPER PERSPECTIVE:
- ReturnsModal now has optional props:
  * prefilledTransactionId - Auto-load transaction
  * prefilledCustomerId - Pre-fill customer
  * onComplete - Refresh callback
- Single modal handles both POS and Customer Profile
- No code duplication

KEY DESIGN DECISIONS
================================================================================

1. REUSE OVER REBUILD
   - Used existing ReturnsModal instead of building a new one
   - Made it smart with optional props
   - Saves code duplication and maintenance

2. EXPANDABLE TRANSACTIONS
   - Click to expand/collapse instead of modal
   - Shows summary in context
   - Better UX than navigation away

3. AUTO-REFRESH
   - After return, automatically reload customer data
   - User sees new status immediately
   - No manual refresh needed

4. PRE-FILLING
   - Transaction ID and Customer ID pre-filled
   - Skip lookup step
   - Jump straight to item selection
